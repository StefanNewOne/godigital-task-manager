# План: Мета модул — усогласување со прототипот (fidelity)

**Тип:** повеќе-фазна дизајн-водена работа (не Hotfix/Improvement).
**Цел:** UI/копи фиделитет на модулот „Мета" кон `design_handoff_meta/prototype/GoDigital Task Manager v3.dc.html` — да ги покрие сите **10 прототип екрани** пиксел/копи-точно, задржувајќи ја постоечката (верна) backend логика (state machine, guards, D1 read-only).

**Извор на вистина:** прототип HTML за распоред/копи (§8 — FE е дизајн-водена); `META_TECH_SPEC.md` за логика (§0). Токени од `packages/ui`. Сите стрингови на кирилица; идеално во `packages/ui/i18n/mk.json` (тековно се hardcoded во `MetaScreen.tsx` — ова е прилика да се средат).

## Фази (секоја = посебен PR во `develop`, gate: typecheck+lint+test+build зелено)

### MF0 — i18n runtime (предуслов) ✅

Причина: `mk.json` постоеше но никаде не се консумираше; целата апликација е hardcoded (TD-10). Сопственикот избра „изгради runtime прво".

- `@gd/ui`: `t(key, vars?)` (dot-lookup + `{var}` + ICU plural со balanced-brace скенер) + `plural(n, forms)` + `pluralCategory` (македонски one/few/other).
- `mk.json`: додаден `meta.tabs` + `meta.topbar` (seed за MF1).
- Прв реален upotreba: таб-етикетите во `MetaScreen` преку `t('meta.tabs.*')` (+ именување fix: „Пресек низ клиенти", „Асистент").
- Тест: `apps/web/src/lib/i18n.test.ts` (lookup, missing→key, интерполација, ICU plural од mk.json, deadline текст+plural).
- Остатокот од апликацијата → TD-10 (посебна chore).

### MF1 — Заеднички топ-бар + именување + евтини копи-поправки

**FE:** `MetaScreen.tsx`

- Заеднички топ-бар над сите под-екрани: глобален **period selector** (7 дена / 30 дена / Овој месец) што го држи периодот во URL/Zustand и го напојува Пресек/Клиент/структура; **филтер-чип по клиент** (точка+име+✕ „Сите клиенти"); **freshness** текст (последен sync); копче **„Освежи сега"** (invalidate + cron trigger); **assistant toggle** (види MF6).
- Именување: таб **„Пресек низ клиенти"**, таб **„Асистент"** (од „Помошник").
- Копи/боја: Коментари „поплака"→**„жалба"**; badge „прашање" → **сино** (`#0369A1`/`#E0F2FE`); „Направено во Ads Manager" → **сино**; footer текстови на Клиенти/Пресек; placeholder на асистент „Прашај или побарај промена…".
- „Отвори во Meta" / „Отвори во Ads Manager" копчиња (deep-link) во Инбокс/Коментари/Планови (external link, `target=_blank`).

**BE:** cron trigger endpoint за „Освежи сега" (постои `meta-*` cron; додади authenticated `POST /meta/refresh` што ги вика sync-овите за тековен/сите клиенти).

### MF2 — „Мета · Клиент" детал со табови (најголема)

**BE:**

- `GET /meta/clients/:id/organic?period=` — IG постови од `MetricSnapshot` (KPI + листа со thumbnail/метрики/„во реклама"/sort).
- `GET /meta/clients/:id/profile` + `PATCH` (само dir) — цели/прагови (metaTargetText, metaMaxDailyBudget, metaFreqThreshold, metaCprAlertPct, metaNamingConvention, metaNotes).
- Прошири `metaClientStructure` за master-detail на ad set (KPI грид, листа реклами со reviewStatus/thumbnail/CTA, линк до таск, `campOps`/`setOps` копчиња што отвораат нацрт-план).
  **FE:** нов `MetaClientDetail` со заглавие (име+боја+access badge+мета) + `mcTabs`:
- **Реклами**: read-only банер („Партнер пристапот е „View performance"…"), master-detail (структура лево + ad set панел десно), „+ Нова кампања" (ако canPropose), акции → `CreatePlanModal`.
- **Органика**: KPI + pill филтри + sort + post картички + v26 footer.
- **Профил**: „Цели и прагови" + „Белешки за клиентот" (textarea, Зачувај само dir).
- Замени го `StructureView` drill-in со овој екран (структурата станува табот „Реклами").
